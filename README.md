# Приложение java-filmorate
Приложение, позволяющее работать с фильмами и оценками пользователей, получать список популярных фильмов по заданным критериям, а также список фильмов рекомендованных к просмотру.

## Реализованный функционал:
- Функциональность «Лента событий» [#14](https://github.com/SeRion525/java-filmorate/pull/14)
- Функциональность «Отзывы» [#10](https://github.com/SeRion525/java-filmorate/pull/10)
- Функциональность «Рекомендации» [#15](https://github.com/SeRion525/java-filmorate/pull/15)
- Удаление фильмов и пользователей [#13](https://github.com/SeRion525/java-filmorate/pull/13)
- Добавление режиссеров в фильмы [#7](https://github.com/SeRion525/java-filmorate/pull/7)
- Функциональность «Общие фильмы» [#17](https://github.com/SeRion525/java-filmorate/pull/17)
- Функциональность «Поиск» [#16](https://github.com/SeRion525/java-filmorate/pull/16)
- Вывод самых популярных фильмов по жанру и годам [#11](https://github.com/SeRion525/java-filmorate/pull/11)
